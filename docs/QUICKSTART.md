# Quickstart

1. Install Docker Desktop.
2. `cp .env.example .env`.
3. `docker compose up --build`.
4. Open `http://localhost:3000`.
5. Demo credentials are the values in `.env`.
6. Register/run the seeded offline scene. The detector uses the bundled ML model and marks synthetic input clearly.
7. The AIS page starts in demo-replay mode and the email page uses a demo outbox.
